# 备考节奏

一个给考公（国考 / 省考，行测 + 申论）用的备考计划工具。

输入考试日期和每天能学的时间，它排出阶段大纲和每日任务；每天打卡；每周根据完成情况自动重排后面的计划。

**当前版本不联网、不调用 AI、不需要注册。** 所有计算都是本地的确定性代码，数据存在你自己的浏览器里。

---

## 怎么打开

双击目录里的 **`启动.bat`**。浏览器会自动打开 `http://localhost:5173`。

想看体验模式（今日页顶上那条模拟工具），双击 **`启动体验模式.bat`**，
它打开的是 `http://localhost:5173/?demo=1`。两个脚本用的是同一个服务，
同时开着也没关系。

想在手机上用：保持手机和电脑连同一个 Wi-Fi，启动后在黑窗口里会打印一个 `http://192.168.x.x:5173` 的地址，用手机浏览器打开它。

关掉那个黑窗口就是停止。

## 发给朋友看

这个工具是**纯静态的**——没有后端、没有数据库、不联网。`启动.bat` 和 `server.js` 只是我开发时图方便，工具本身不需要服务器。所以它可以放到任何静态托管上，变成一个网址。

### 最快的路径：GitHub Pages

1. 注册 GitHub 账号（github.com，免费）
2. 右上角 **+** → New repository，名字随便（比如 `kaogong-plan`），选 **Public**，创建
3. 进仓库 → **Add file** → **Upload files** → 把这个文件夹里的 `index.html`、`css`、`js` 拖进去 → Commit
4. 仓库 → **Settings** → 左侧 **Pages** → Source 选 `main` 分支和 `/ (root)` → Save
5. 等一两分钟，地址就是 `https://你的用户名.github.io/kaogong-plan/`

这个地址发给朋友，手机电脑都能打开。iOS 的 Safari、安卓的 Chrome 都可以。

> GitHub Pages 在国内访问有时候会慢。如果朋友打不开，换 Cloudflare Pages（同样是免费静态托管，流程类似）一般会好一些。

### 部署完要注意两件事

**你和朋友的数据是两套，互相看不到。** 计划、打卡记录都存在各自的浏览器里，不会汇总到你这里。

**想收朋友的意见，让他自己填一遍问卷用一遍**，然后把感受说给你听，或者点设置页最下面的「导出数据」把 json 发给你。这份数据里包含他填的问卷、每天的打卡记录和用时统计，比口头反馈具体得多。

另外提醒一句：清浏览器缓存会把数据清掉，重要的话记得定期导出备份。

### 让它在手机上像个 App（推荐就这么发给朋友）

项目里已经挂好了"添加到主屏幕"需要的东西，朋友用手机浏览器打开网址之后：

- **iPhone**：用 Safari 打开 → 底部「分享」→ 往下翻找「添加到主屏幕」→ 添加
- **安卓**：用 Chrome 打开 → 右上角「⋮」→「添加到主屏幕」或「安装应用」

加完之后桌面上会多一个图标（香槟金底、白色对勾），点开是全屏的，没有地址栏，
断网也能打开。跟装了个 App 一样，但是不用注册开发者账号、不用备案、不用等审核。

想换图标就改 `tools/make-icons.js` 顶部的颜色和对勾形状，然后
`node tools/make-icons.js` 重新生成，不用装任何东西。

> 离线缓存只在正式网址（https）上生效，本地 `启动.bat` 的 `localhost` 不会装——
> 不然你改完代码刷新还是旧的，会以为没生效。

### 体验模式：让朋友一次看完"坚持一个月会怎样"

朋友刚打开只看到今天。想让他们看到"练了三周之后计划会变成什么样"，
在网址后面加一个参数：

```
https://xiaoyang2708.github.io/jihuamoni/?demo=1
```

今日页顶上会多出一条工具条，最常用的三个按钮就一行：

- **模拟完成今天**：按完成率（默认 75%）把今天的打卡填上
- **下一天 →** / **← 前一天**：一天一天往前走，也可以回头
- **更多模拟选项**：完成率（全部 / 95% / 75% / 50%）、自动跑 7 / 30 天、
  跳到某一天、模拟停更 5 / 12 天、回到真实今天、重新开始

关键的一条：**往回走改完再往前走，后面的计划会按你改过的数据重新算。**
回到第 3 天把它改成"没完成"，再走一遍，就能看到后面两周确实减量了。
想试更狠的用「从这天重来」——把这天之后的记录清掉，从这天重新往下排。

走的是引擎里的真实逻辑（周重排、任务顺延、断更重启、阶段推进），不是另外演一套假的。

这样开过一次就记住了：之后打开普通网址、换个标签、刷新，工具条都还在。
想彻底退出，点工具条最下面的「退出体验模式」——它会连这个记忆一起清掉。

> 为什么记在本地：只认网址的话，换个标签、从收藏夹打开、点一次「退出」，
> 工具就没了，还得自己记得把 `?demo=1` 加回去。评审阶段天天要用，太烦。

> **朋友玩完想正经用**，点工具条里的「重新开始（回到问卷）」就干净了，
> 跟设置页最下面那个「重新开始」是同一个动作。

### 正式开卖之前：把体验模式删干净

体验模式只给朋友试用，正式版不该有。删的时候一共四处，注释里都写了「体验模式」：

1. 删掉 `js/demo.js`
2. `index.html` 里删掉 `<script src="js/demo.js"></script>` 那一行
3. `js/app.js` 里搜「体验模式」，删掉 `demoCtx()` 那一段、`demoOn()`、
   `renderToday()` 里的 `demoBar` 那一行、`render()` 里的 `decorate()` 那一行
4. `css/styles.css` 最后那段标了「体验模式」的样式，可删可留（没人引用就没事）

**不要删** `manifest.webmanifest`、`sw.js`、`icons/`——那是"添加到主屏幕"用的，正式版也要留。

## 怎么改计划内容

**你不需要改代码。** 所有和考公专业判断有关的参数都在两个地方：

### 1. 界面里能直接改的

设置页里可以改：考试日期、每天可用时间、休息日、每节课时长、听课倍速、各模块强度（加强 / 正常 / 减少 / 不学）。

**改完立刻生效**，后面的计划自动重排（输入框停手约 0.4 秒就重算，点选类的立刻重算）。
设置页最下面那行会写清这次变了什么，比如「已重排：基础期 33→50 · 听课时长 63→84 小时」。

**已经打过的卡不会被删掉。** 所以还有一个副作用要留意：
**已经动过的那些天（打过卡、选过感受、自己加过任务）不会被覆盖**，
只有没动过的日子才会按新设置重排。设置页在变化从明天开始时也会说明一句。

### 2. 配置文件

打开 `js/config.js`，里面是骨架参数：

- `YT.MODULES` —— 模块顺序（`order`）、每个模块做一道题大概几分钟（`unitMinutes`）、默认课节数（`courseUnits`）
- `YT.ESSAY` —— 申论小题和大作文的固定时长
- `YT.CONFIG.split` —— 每天的时间怎么分给听课和刷题
- `YT.CONFIG.stage` —— 三个阶段各占多少比例
- `YT.CONFIG.reflow` —— 完成率低于多少就减量、减多少
- `YT.BASE_PRESET` —— 不同基础的人，基础期占多久

改完存盘、刷新页面就行，不用重新安装什么。

## 字体

界面用的是**思源黑体**（Noto Sans SC，OFL 协议，免费商用）。

完整版是 16.9 MB，不能直接当网页字体用。但这个工具里显示的中文**全部出自程序自己的字符串**，没有用户自由输入，所以用到的字是固定的——`tools/make-font-subset.py` 会把源码扫一遍，把出现过的字挑出来单独打包，产物是 `fonts/noto-sans-sc-subset.woff2`，346 KB。

它还额外塞了 ASCII、全部数字、中英文标点，以及一份常用字兜底，所以以后加新文案、或者用户导入的旧数据里出现生僻字，也不会掉方框（真掉也会自动回退到系统字体）。

**改了界面文案之后，重新跑一次：**

```
python tools/make-font-subset.py
```

为什么非要自托管：字体栈里原本第一位是「苹方」，那是苹果独有的，到了 Windows 会一路回退到微软雅黑——一款 2006 年的字体，而且只有两个字重，界面里 `font-weight: 600 / 650` 这些全是浏览器描出来的假粗体，笔画会糊。自托管保证所有设备看到的是同一款字。

> 也考虑过用 Google Fonts，但它国内经常打不开，你的用户大多在国内，所以走自托管。
> 字体子集是构建产物，改了文案没重新生成的话，新字会回退到系统字体——不会坏，只是那一个字长得不一样。

## 主题色

设置页里能直接换，七个颜色。实现是 `html[data-theme]` 上挂一组 CSS 变量，换色是瞬时的，不重排计划、不动数据。

一个主题只要四个值：主色、亮色（按钮上缘高光）、深色（按钮下缘收边）、字色（压在主色上的字）。

**加新主题要改两个地方，id 必须一致：**

1. `js/config.js` 的 `YT.THEMES` 里加一条
2. `css/styles.css` 里抄一段 `html[data-theme="同名的 id"]`，把那四个变量写进去

**警告橙、危险红、半完成琥珀、三个阶段的配色故意不跟主题走。** 它们表达的是状态，不是品牌——换个主题颜色就变，用户会看不懂。

## 已经做了什么

- 申论是**独立的一条线**：按"本周总时长 × 占比（默认 35%）"单独给预算，不跟行测抢模块队列。预算能滚存——工作日塞不下就攒到周末。听课和练题交替进行，听完一节课就练对应的题
- 行测刷题按性价比加权：资料 / 言语 / 判断推理出现得更频繁，数量、常识、政治理论压低
- 7 步引导问卷：考试日期、当前基础、工作日时长、周末时长、休息日、使用模式、各模块课节数
- 阶段大纲：基础期 / 强化期 / 冲刺期，系统按课时量和考试日期给推荐值；用户可以在设置里改「基础期结束」和「冲刺期开始」两个日期
- 每日任务：听课、刷题、申论、错题复盘，题量按模块「每题基准分钟」折算
- 计划页可以切「本周 / 两周 / 30 天」三种跨度，逐天看接下来要做什么
- 打卡：三态（完成 / 半完成 / 未完成），可选填实际用时
- 每日感受：太轻松 / 刚好 / 有点累 / 太难了。选完**立刻**按最近一次感受重排后面还没开始的天，并在当页列出"哪一项从多少变成多少"，再点一下可以取消
- 每周重排：跨周时自动按上周完成率加量、保持、减量或降档，只重排本周还没动过的日子，打过卡的记录一律不动
- 任务顺延：没做完的顺延到后面的学习日，但不超过单日容量的 120%，超出的直接砍掉，不让任务堆积
- 休息日：不排任务，不算漏打卡，不断连续天数
- 统计：做题速度中位数、连续打卡、累计完成率
- 导出 / 导入数据
- 课时量体检：算出按当前节数和倍速，听课需要多少个学习日，排不下会在计划页给出提示和调整建议
- 计划页三种粒度用三种展示：**本周**展开看细节，**两周**折叠成摘要行便于扫，**本月**用日历——一个月本来就是一屏的事
- 高级参数可以在设置里改：申论占比、复盘系数、复盘时长上限、感受调整幅度、单科每日上限、单日听课上限。默认值就是推荐值，也可以一键恢复
- 体验模式（`?demo=1`）：今日页顶上的工具条，「模拟完成今天 → 下一天」一路点下去，
  也可以往回走改某一天再看后面怎么重排；能模拟停更 5 / 12 天，看断更重启跑出来什么样
- 加到手机桌面：manifest + 图标 + 离线缓存，全屏打开、断网可用，不用审核不用备案

## 几个刻意的设计

这几条是实现里特意做的，改代码前建议先看一眼，不然容易改坏：

**提前排好的计划不算失败。** 系统会预排未来两周，这时候"下周"的任务当然全是未完成。所以重排规则只在某一周**真正过完**之后才生效，否则会自己把计划越排越少。见 `engine.js` 的 `reflowForDate` 和 `rollWeek`。

**复盘单独成一项。** 不混进刷题时长里，这样能单独打卡，也能看出用户到底复盘了没有。复盘时长到 60 分钟封顶，再长没意义，多出来的时间还给刷题。

**感受只调整刷题和复盘，不调整听课。** 一开始是把一整天按系数缩放，结果选"太难了"时刷题反而从 45 题涨到 50 题——听课按半节取整被砍掉一大块，腾出来的时间全回流到刷题上了，信号完全是反的。课程进度交给每周完成率那条规则去管，那里的信号更可靠。

**未完成的任务不简单加倍补。** 某个模块完成率低，说明有障碍，下周是减量或延后，不是翻倍。

**单日题量不硬拆。** 一个模块至少要分到 20 分钟才会单独排一项，否则宁可不拆，免得出现"5 题"这种没有意义的任务。

**单科任务有上限，超了就分组。** 同一科一天超过 120 分钟会拆成「刷题（1/2）」「刷题（2/2）」；听课一天超过 2 节会拆成两条。全职备考一天 9 小时的话，不拆会看到"资料分析 150 题""连听 5 小时"这种一条顶一整天的任务，光是看着就不想开始。

**确认框是自己画的。** 没用浏览器原生 `confirm()`——手机上难看，而且微信小程序里没有这个函数。

**底部那行状态要避开导航栏。** `.sticky-cta.above-tabs` 这个类是必须的：设置页底部那行"设置改完会自动重排"如果不抬高，会被固定的底部导航盖住。这个坑踩过一次。

**设置改完自动重排，不再需要手点按钮。** 原来设置页最下面是个「重新生成后面的计划」按钮，
但设置页很长，改数字的地方离按钮很远，用户改完往下一看计划没动就以为设置没生效。
现在输入框停手约 0.4 秒就重算（`scheduleRegen`），点选类（强度、顺序、休息日）立刻重算。
重排是静默的：不弹进度层、不跳页，只把设置页里跟着变的数字刷新一遍，
并把焦点和光标还回原来的输入框（`reRenderKeepPlace`），不然打字打到一半就被踢出来了。
